Adidas Sales Analysis Dashboard (Excel & Power Query)
📊 Project Overview

This project analyzes Adidas sales data using Microsoft Excel and Power Query.
The goal is to transform raw sales files into a clean dataset and build an interactive dashboard that highlights key business KPIs and regional performance.

The project demonstrates an end-to-end data analysis workflow, from data ingestion and cleaning to reporting and visualization.

🧰 Tools & Technologies

Microsoft Excel

Power Query (M Language)

Pivot Tables & Pivot Charts

Excel Slicers

📂 Data Source

Sales data stored in multiple files

Includes transaction dates, regions, sales, unit prices, profits, and retailers

🔄 Data Processing Workflow
1️⃣ Data Import

Imported multiple files from a folder using Power Query

Automatically combined all files into a single dataset

2️⃣ Data Cleaning

Handled missing values and errors

Removed blank records

Standardized column names

Corrected data types (date, numeric, text)

Applied consistent formatting

3️⃣ Date Transformation

Used the date column to generate:

Year

Quarter

Month

Day

These fields enable time-based analysis and filtering in the dashboard.
